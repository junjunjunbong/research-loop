# Roadmap

## v0 — local bootstrap

- one Codex/Agent Skill
- deterministic project inspection and generated Research Profile
- one plan-hash campaign approval
- isolated local CPU/light experiments
- authoritative metric parsing, compatibility checks, ledger, and recovery

## Next

- validate against a real retrieval/RAG repository without introducing a required retrieval module
- add richer evidence-based command discovery and profile confidence reporting
- support configurable seed scheduling and statistical confirmation
- add explicit user-approved GPU resource contracts
- add remote execution providers only behind the same Execution Contract boundary

## Later

- optional research knowledge packs as hypothesis-generation inputs
- branch comparison and user-driven promotion/merge workflows
- campaign visualization and multi-project summaries
